# Mind Share

Mind Share is a hackathon project (built on a Next.js/Mastra monorepo starter) exploring a **Human Context Protocol**: each person gets a living Context Agent built from their Drive/Slack/Gmail, and other people's agents can only reach it through an MCP-exposed **Context Firewall** — a policy layer that decides what's disclosable (classification + RBAC) and blocks requests that would let someone infer a protected fact from otherwise-harmless pieces. Every exchange produces a visible disclosure receipt and an audit log entry.
